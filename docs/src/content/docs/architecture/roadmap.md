The FinFocus roadmap is maintained in the repository, next to the issues it
tracks, so it is always current:

- [ROADMAP.md](https://github.com/rshade/finfocus/blob/main/ROADMAP.md) — the
  near-term focus, later plans, and completed milestones
- [Open issues](https://github.com/rshade/finfocus/issues) — individual work
  items, each linked from the roadmap
- [Releases](https://github.com/rshade/finfocus/releases) — what shipped in each
  version
